Planned features

How it works

Record. Refine. Share.

Record

Pick a display, window or area. Screen, webcam, microphone and system audio are saved as separate tracks, with cursor and click events kept alongside.

Refine

Open the project in the editor. Everything is non-destructive, so zoom, crop, camera, cursor and background can change without recording again.

Share

Export to a folder you choose. The preview and the export use the same rendering, so what you see is what you get.

Privacy

Your recordings never leave your computer

There is no account to create and no cloud to upload to. The app does not need a server to do its job.

  • No sign-in, subscription, watermark or export cap.
  • No analytics or telemetry in the app.
  • Projects and media stay on your disk, in a plain project folder.
  • Cursor tracking records position and clicks only. It never records what you type.
  • Internet is optional: only for downloading caption models or checking for updates.

FAQ

Questions

Is it really free?

Yes. The plan is no subscription, no account, no watermark and no export limit. There are no paid services behind it.

Can I download it now?

A Mac prototype for Apple Silicon is available above. There is no Windows build and no Intel Mac build yet. The Mac build is not notarized, so macOS will warn you the first time you open it.

What works today?

A macOS prototype has a floating recorder (display, window or area, with camera, microphone and system-audio menus), records into separate files, keeps cursor events, and has an editor with backgrounds, zoom, cursor effects, masks, trim and MP4 export. It has 40 automated tests, but it has not been tested on a wide range of real recordings, there is no installer, and Windows is not started.

Does it upload my videos?

No. Recording, editing, captioning and export all happen on your device.

Is it a copy of another app?

No. It is an independent project with its own code, icons, name and look. It draws on the same kind of workflow that polished screen recorders use.

Why will the installer show a warning?

Notarization and code signing cost money and need paid developer accounts. If we ship unsigned builds, macOS and Windows will warn you on first launch, and the release notes will explain how to open them.
